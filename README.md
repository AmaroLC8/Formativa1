# Proyecto Tienda Web - Desarrollo Fullstack II 🚀

Este proyecto es una aplicación web básica desarrollada para la asignatura **Desarrollo Fullstack II (DSY1104)**. Consiste en la maquetación y desarrollo de una tienda web, implementando un sistema de registro funcional, diseño responsivo y la integración de diferentes tecnologías frontend.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **HTML5:** Para la estructura semántica y el etiquetado del sitio.
* **CSS3:** Para los estilos personalizados (colores, fuentes y disposición).
* **JavaScript:** Para la lógica de validación de los formularios interactivos.
* **Bootstrap:** Framework implementado mediante CDN para agilizar el diseño responsivo y el uso de componentes predefinidos.

## 📂 Estructura del Proyecto
El proyecto sigue las buenas prácticas de organización de archivos:
* `index.html`: Página principal y formulario de registro.
* `assets/img/`: Directorio que contiene todas las imágenes locales utilizadas en el sitio.
* `assets/style.css`: Hoja de estilos externa para la personalización de la interfaz.

## 💻 Cómo ejecutar el proyecto
1. Clona o descarga este repositorio en tu computador.
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo `index.html` para abrirlo directamente en tu navegador web de preferencia (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.).
